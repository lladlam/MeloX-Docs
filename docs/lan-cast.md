# 局域网一起放

局域网一起放用于在同一网络中的设备间协调播放。参与设备需要运行兼容版本的弥乐，并处于可互相访问的网络环境。

## 连接前检查

- 设备连接到同一 Wi-Fi 或可互通的局域网；访客网络、客户端隔离或 VPN 可能阻断设备发现。
- Android 系统允许弥乐使用所需的附近设备/网络权限。
- 设备保持亮屏或允许弥乐在后台运行，以便维持连接。

## 使用

从设备互联或局域网一起放入口发起会话，再在其他设备上加入。主设备控制队列、切歌和跳转；网络延迟与设备解码差异会造成播放位置偏差。

若无法发现设备，先确认同网段互通、关闭路由器客户端隔离后重试。特定路由器或系统防火墙可能阻止发现或连接。
