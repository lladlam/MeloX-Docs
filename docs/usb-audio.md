# USB 独占输出（实验性）

USB 独占输出用于将音频直接发送到兼容的 USB DAC。当前实现仍是实验性功能，不能保证所有手机、转接头或 DAC 均可工作。

## 当前支持范围

- UAC1 全速与高速设备。
- 双声道 PCM、UAC1 自适应或同步 OUT 等时端点。
- 设备描述符支持的 PCM 容器范围有限；24/32 位容器由 PCM16 左对齐补零，不代表真实高位深解码，也不宣称 bit-perfect。

当前不支持 UAC2、异步反馈、多事务端点和 DSD。即使设备能被 Android 识别，也不代表当前 USB 驱动能够驱动它。

## 连接与播放

1. 使用支持 USB OTG 的手机和可靠的 OTG 转接头连接 DAC。
2. 在系统授权提示中允许弥乐访问 USB 音频设备。
3. 在设备输出中选择 USB 独占并开始播放。

拔插设备、切换其他输出路径或暂停/恢复时，播放状态可能短暂变化。自动混音与 USB 独占输出互斥。

## 兼容性排查

- 更换 OTG 转接头或确认手机支持 USB Host/OTG。
- 尝试断开并重新连接 DAC，再重新授权。
- 如果仍失败，在“设置 → 关于”导出 MeloX 全部日志。导出内容包含最近一次 USB 尝试的速度、接口描述符和失败原因，不采集 USB 序列号字符串；发送前仍建议检查整个日志是否包含个人信息。
- UAC2、异步反馈等当前未支持设备无法通过普通设置解决。
