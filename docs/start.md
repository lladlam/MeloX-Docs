# 欢迎使用弥乐

弥乐（MeloX Android）是基于 Kotlin、Jetpack Compose 与 AndroidX Media3 构建的原生 Android 音乐播放器。这里介绍下载安装、音源、播放、设备输出和常见问题。

> 弥乐是非官方开源项目，与网易云音乐、小米、Apple 及其关联公司不存在隶属、合作或授权关系。第三方音源依赖外部服务，接口、可用地区及播放链接可能随时变化。

## 快速入口

- [下载与安装](installation)：选择适合设备架构的 APK 并完成安装。
- [首次启动](first-launch)：完成欢迎流程、隐私说明和基础设置。
- [音乐音源](music-sources)：了解内置音源和第三方音源脚本。
- [播放与歌词](playback-and-lyrics)：音质、播放队列、歌词与播放问题。
- [局域网一起放](lan-cast) · [USB 独占输出](usb-audio)
- [故障排查](troubleshooting) · [隐私与日志](privacy-and-logs) · [常见问题](faq)

## 版本与支持

正式版、开发版和完整更新日志请查看 [GitHub Releases](https://github.com/lladlam/MeloX-Android/releases)。遇到问题时，请先查看故障排查文档，再导出日志并检查其中的个人信息后提交反馈。

当前文档对应的正式版本基线：**0.7.1**。功能状态可能随新版本变化。
