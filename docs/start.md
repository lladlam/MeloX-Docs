# 欢迎使用弥乐

弥乐（MeloX）包含 Android、Windows 与 Linux 客户端。本网站提供各平台项目入口和当前状态，并整理已核实的平台使用说明。不同平台仍处于不同开发阶段，功能和操作方式不保证完全一致。

> 弥乐是非官方开源项目，与网易云音乐、小米、Apple 及其关联公司不存在隶属、合作或授权关系。第三方音源依赖外部服务，接口、可用地区及播放链接可能随时变化。

## 版本与支持

各平台仓库、发布渠道和问题反馈入口见[平台与版本状态](platforms)。遇到问题时，请先查看故障排查文档，再按对应平台提供信息；分享日志前检查其中的个人信息。

Android 指南当前正式版本基线：**0.7.1**。Windows/Linux 的功能与发行状态以各自仓库说明为准；功能状态可能随新版本变化。
