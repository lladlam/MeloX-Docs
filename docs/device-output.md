# 输出设备、DLNA 与 MiPlay

本页说明 Android 播放设备面板中的功能；Windows/Linux 桌面音频路由请参考各自项目说明。

播放器的“播放设备”入口用于选择手机扬声器或当前连接的外部输出。Android 系统蓝牙/有线设备由系统音频路由管理；弥乐还支持 DLNA 渲染器和部分小米 MiPlay 接收设备。USB 独占有单独的实验性驱动路径，见 [USB 独占输出](usb-audio)。

## DLNA 音箱或电视

1. 确认手机与音箱/电视接入同一可互通的局域网，接收设备已打开 DLNA/媒体投放能力。
2. 在播放设备面板查看“局域网音箱/电视（DLNA）”列表并刷新发现。
3. 选择设备后开始投放；可用的播放、暂停、进度和音量控制取决于渲染器实现。
4. 结束时从播放设备面板断开设备，或停止投放。

DLNA 设备发现使用局域网组播。访客网络、AP 客户端隔离、VPN、防火墙和部分路由器可能阻止发现。不同电视/音箱对 URL、格式、Seek 和音量的支持不一致；列表发现成功不代表所有歌曲格式都能播放。

## 小米 MiPlay

MiPlay 使用小米设备/互联服务提供的接收路径，不等于 DLNA，也不等于弥乐自己的 LAN Cast。连接能力取决于手机系统版本、小米服务组件和接收设备型号。打开播放设备面板后查看 Xiaomi MiPlay 设备列表，选择目标设备连接；用面板中的断开入口结束会话。

若列表为空，确认手机和接收设备在同一局域网，相关系统服务可用，并检查系统的附近设备/局域网权限。非小米设备或不支持 MiPlay 的系统可能不会显示此类设备；可尝试标准 DLNA（若接收端支持）。

## 输出切换注意事项

- 蓝牙/有线设备通常由 Android 自动路由；连接或断开时观察播放器设备选择器中的当前输出。
- DLNA、MiPlay、弥乐 LAN 投放/一起放和 USB 独占是不同输出或互联会话，部分模式之间互斥。
- 输出切换时若本地扬声器与外部设备同时出声，停止当前投放并重新选择输出。
- DLNA/MiPlay 实际表现依赖接收设备固件；发现成功、连接成功和持续播放成功是不同阶段。

## 无法发现或播放

1. 确认两台设备处在同一可互通网络，关闭路由器的客户端隔离/访客网络后再试。
2. 检查 Android 权限、接收端投屏设置和设备是否在线。
3. 尝试另一首曲目，排除接收端不支持当前资源格式或媒体地址。
4. 断开旧会话、重新扫描并连接。
5. 仍失败时导出日志，并在报告中注明接收设备型号、系统版本、连接模式和失败阶段。
