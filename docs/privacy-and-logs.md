# 隐私与日志

弥乐可能在设备本地保存音源账号状态、播放记录、偏好设置、缓存和第三方源配置，以提供应用功能。联网使用音乐服务、脚本、云控或设备连接时，会向相应服务发送完成该功能所需的请求；第三方服务受其自身隐私政策和运营规则约束。

## 导出日志

在应用内进入“设置 → 关于”，使用“导出 MeloX 全部日志”。如问题涉及 USB 输出，先复现一次再导出，以便日志包含最近一次 USB 设备尝试的诊断信息。

日志可用于定位启动、账号、网络、播放和设备连接问题。USB 诊断段包括最近尝试的速度查询结果、音频接口描述符和失败原因；USB 序列号字符串不会被这段诊断采集。

## 分享前检查

日志可能包含账号状态、歌曲和播放信息、请求 URL、设备信息或第三方服务响应。应用会对部分 URL 或敏感参数进行脱敏，但不同服务响应格式复杂，**不能假设日志已完全匿名**。

分享前请在文本编辑器中检查导出文件，删除不愿公开的内容，并只通过可信渠道分享。不要公开发送密码、Cookie、访问令牌、个人 API Key、私有播放链接、家庭服务器地址或个人联系方式。

如果日志太大或无法安全公开，可先在 [GitHub Issues](https://github.com/lladlam/MeloX-Android/issues) 描述复现步骤，说明你有日志可提供，并询问维护者合适的提交方式；不要把敏感日志直接附到公开讨论。
