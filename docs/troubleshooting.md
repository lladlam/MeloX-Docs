# 故障排查

先记录发生问题的时间、应用版本、Android 版本和复现步骤。一次只改变一个设置，避免同时更改音源、网络和输出后无法判断原因。

## 歌曲无法播放

1. 检查网络连接，并确认目标音源或账号当前可用。
2. 试播同一音源的其他歌曲，区分单曲资源问题和整个音源问题。
3. 检查账号权益、地区限制、音质设置和第三方脚本状态。
4. 更新应用到最新正式版；如使用第三方脚本，检查来源并从可信渠道更新。
5. 若启用了跨平台回退，确认参与音源列表中有可用服务；第三方解析还需单独启用并接受协议。
6. 仍无法解决时导出日志并检查后再提交反馈。

如果能播放其他歌曲，问题更可能与该曲目的资源、版本或权限有关；如果整个音源都失败，再检查该服务登录状态和网络接口状态。

## 有播放进度但听不到声音

- 检查手机媒体音量、静音状态、蓝牙设备和播放器的当前输出选择。
- 切回手机扬声器进行对照，确认问题是否只出现在某一个外接设备。
- Cast 时接收设备负责出声；控制模式只发控制指令，不传音频；Transfer 则由接收端重新解析曲目。
- USB 独占需要受支持的 UAC1 设备和 USB 授权，查看 [USB 独占输出](usb-audio)的限制。
- 系统媒体控制或后台播放异常时，检查 Android/OEM 的后台运行和通知权限。

## 登录或账号功能异常

确认登录的是目标音源账号，并检查系统时间、网络和服务端登录状态。不同音源账号相互独立。可只对该音源重新登录；退出/重新登录会清除本机保存的该服务会话，不会退出其他服务。请勿在公开反馈中粘贴 Cookie、令牌或完整请求链接。

## 歌词缺失或不同步

确认歌曲资源和网络正常，尝试重新加载歌词，并检查是否匹配到不同录音版本（现场、翻唱、剪辑）。逐字歌词依赖源数据提供时间轴；没有逐字时间数据时可能只显示逐行效果。悬浮歌词还需要 Android 的悬浮窗权限，系统通知歌词则受系统/OEM 限制。

## 设备连接不到

- **LAN 一起放**：确认设备在同一个可互通的局域网，关闭路由器客户端隔离后再试；核对配对 PIN 和常用设备状态。
- **DLNA/MiPlay**：确认接收设备已开机且连接同一网络；部分路由器会阻止发现广播。
- **USB**：重新插拔并确认系统 USB 授权，查看 [USB 独占输出](usb-audio)的协议支持范围。

## 下载或本地歌曲异常

检查网络、音源权限和剩余空间。下载任务失败时先试单曲；本地歌曲未出现时检查媒体读取权限或文件夹授权，再重新扫描。

## 安装或升级异常

确认 APK 架构与设备匹配。正式版和开发版签名不同，不能直接覆盖安装；卸载会清除应用数据，操作前请确认备份。

## 反馈问题时提供什么

参考[如何有效反馈问题](asking-for-help)填写复现步骤、预期/实际结果、设备和版本信息。必要时从“设置 → 关于”导出日志；日志分享前请检查并移除敏感内容。
