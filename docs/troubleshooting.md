# 故障排查

## 歌曲无法播放

1. 检查网络连接，并确认目标音源或账号当前可用。
2. 试播同一音源的其他歌曲，区分单曲资源问题和整个音源问题。
3. 检查账号权限、地区限制、音质设置和第三方脚本状态。
4. 更新应用到最新正式版；如使用第三方脚本，检查来源并从可信渠道更新。
5. 仍无法解决时导出日志并检查后再提交反馈。

## 登录或账号功能异常

确认登录的是目标音源的账号，并检查系统时间、网络和服务端登录状态。不同音源账号相互独立。请勿在公开反馈中粘贴 Cookie、令牌或完整请求链接。

## 设备连接不到

对于 LAN 一起放，确认设备在同一个可互通的局域网；对于 DLNA/妙播，检查设备发现权限与网络隔离；对于 USB，查看 [USB 独占输出](usb-audio)的支持范围。

## 安装或升级异常

确认 APK 架构与设备匹配。正式版和开发版签名不同，不能直接覆盖安装；卸载会清除应用数据，操作前请确认备份。

## 反馈问题时提供什么

- 弥乐版本、Android 版本和设备型号。
- 问题出现的步骤、预期结果和实际结果。
- 可复现时的时间点，以及相关音源/设备类型。
- 从“设置 → 关于”导出的日志（分享前先检查并移除敏感内容）。
