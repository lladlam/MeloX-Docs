# 插件运行时、生命周期和安全边界

## 安装与信任

设置页使用系统文件选择器导入 ZIP，展示声明的能力、网络/认证权限、包摘要及可选签名指纹。新安装默认禁用；启用前验证入口和必需方法。更新需相同 ID、更高版本；扩权需要确认。包 envelope 包含 SHA-256 清单，可选 RSA-SHA256 签名；首次信任是本地 TOFU，换发布者或签名降级的批准绑定具体候选包哈希。签名不保证插件代码安全，也不证明发布者现实身份。

包与发布者信任记录使用预写恢复日志；启用状态是单独提交，并非跨文件全局事务。API 35 转译模拟器 15 组提交/回滚边界进程强杀恢复已通过；物理断电及真实磁盘写失败仍待验收。禁用/卸载撤销 Provider；缺失来源的历史和队列保留其 SourceId，不自动变成内置来源。普通存储和账号凭据可按设置页操作清理。

## 执行与配额

`PluginIsolatedService` 是非导出隔离 UID，脚本无直接 Android Context、文件、Java 桥、Cookie 或网络权限；每次调用使用新 QuickJS Context，HTTP 和 storage 由宿主代理。调用全局串行、每次调用 token 隔离响应。当前 token 的取消和 watchdog 可以终止隔离进程，不杀宿主。

| 项目 | 上限 |
| --- | --- |
| ZIP / 解压 / 文件数 | 4 MiB / 8 MiB / 64 |
| 入口脚本 / 参数 / 返回结果 | 各 128 KiB |
| QuickJS 堆 / 栈 | 16 MiB / 256 KiB |
| worker watchdog / 宿主等待 | 8 秒 / 12 秒 |
| 每次 host 调用 / HTTP 请求 | 32 / 8 |
| API 请求 / 响应体 | 32 KiB / 64 KiB |
| API 重定向 | 最多 3 次，逐跳检查 |
| 插件渐进下载文件 | 512 MiB |

运行时诊断仅持久化受控方法、错误码、时间和耗时，不保存 Token、请求参数或脚本日志正文；设置页可查看和清除。

## 网络、媒体与凭据

网络仅允许清单声明的公开 HTTPS 443 精确域名；使用独立客户端，不继承应用 Cookie、代理或账号。DNS 结果中有私网/保留地址时拒绝；API 重定向逐跳重新授权，跨域移除原请求头；媒体不自动跟随重定向。下载、播放和封面经宿主网络策略，不共享插件媒体字节缓存。

Token 按插件/账号隔离并通过 Android Keystore 加密；Lease 绑定来源、授权策略及会话版本。插件只可请求宿主向授权域名注入凭据。切号、更新、禁用或运行时关闭会撤销相应请求；已解码或缓冲的音频不保证立即停止。

下载使用 `.part`，校验完成后提升为完成文件。只有强 ETag、范围响应和插件包/账号会话/音质作用域一致时才能续传；重启后任务需用户显式重试，不保存解析后的 URL、请求头或凭据。受控公网 OAuth、续传、连接撤销与 DNS/socket 红队结果仍待完成，不以单测代替。
