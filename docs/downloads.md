# 下载与本地音乐

弥乐支持离线下载及本地音乐浏览。可用的下载音质取决于源服务的资源与账号权限。

## 下载管理

下载任务可在应用内查看进度，并按当前版本提供的控制项暂停或恢复。删除下载文件前请确认操作对象；本地副本与外部导出文件可能位于不同位置。

## 导出与存储

应用可保留应用私有目录中的离线副本，并支持将文件导出到 Android 媒体库。导出后文件由系统媒体库管理，卸载应用时的保留行为可能与应用私有文件不同。

## 本地音乐

首次浏览本地音乐时，按系统提示授予所需媒体访问权限。若歌曲未显示，检查文件是否位于设备可访问的媒体目录，并在应用中重新扫描或刷新列表。
