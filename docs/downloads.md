# 下载与本地音乐

弥乐支持离线下载及本地音乐浏览。可用的下载音质取决于当前源服务、歌曲资源和账号权限。第三方服务可能限制下载或不提供可下载地址。

## 下载管理

从歌曲或内容菜单选择下载后，可在下载页面查看任务状态。具体按钮和可下载音质取决于内容类型与服务能力；批量下载可能按歌曲逐项选择质量。任务失败时先检查网络、目标音源和剩余空间，再重试单曲以区分服务端限制和批量任务问题。

移除下载只会影响弥乐管理的离线副本；如果之前另行导出到系统媒体库或其他文件夹，导出副本需要在对应位置单独管理。删除前确认操作对象和路径。

## 导出与存储

应用可保留应用私有目录中的离线副本，并可导出到 Android MediaStore。应用私有副本受应用存储管理；导出副本由系统媒体库管理，卸载应用时的保留行为可能不同。不要把导出媒体库的副本当作应用私有备份。

## 本地音乐

在“音乐服务 → 本地音乐”选择扫描设备音乐，按系统提示授予媒体读取权限；也可以用系统文件夹选择器添加音乐目录并保留访问授权。扫描只索引设备上的音乐，不会把本地音频上传。

若歌曲未显示，确认文件格式和文件夹权限，再重新扫描。删除文件或撤销目录授权后，库中的条目可能需要刷新。离线文件可在本地库中浏览；本地文件不需要登录音乐服务。
