# 常见问题

### 弥乐需要 Root 吗？

正常播放不需要 Root。USB 独占输出也通过 Android 的 USB 授权和已授权设备接口工作，不要求 Root；但它只支持有限的 UAC1 配置。

### 所有第三方音源都能用吗？

不能保证。第三方音源依赖外部脚本和服务，可能失效、限流、受地区限制或只提供试听资源。请只导入可信来源的脚本，并先阅读第三方音源协议。

### 为什么跨平台搜索或回退没有请求所有音源？

跨平台功能默认关闭；开启后仍需明确选择参与的音源。弥乐不会默认向所有服务同时发请求。账号登录状态和服务可用性也会影响结果。

### 为什么某首歌无法播放，但其他歌可以？

单曲可能受版权、地区、账号权益、资源下架或版本差异影响。尝试切换可用音质或允许已选内置音源严格匹配回退；回退不保证找到资源，也不会用试听片段冒充完整音频。

### 本地音乐会上传吗？

本地音乐库扫描用于读取和索引设备文件；本地文件仍在设备上播放，不会因为扫描操作自动上传。请勿把此说明扩展理解为其他联网功能都离线运行。

### 为什么 USB DAC 被系统识别但弥乐无法使用？

系统识别和当前驱动支持是两回事。当前 USB 独占仅覆盖部分 UAC1 设备，尚不支持 UAC2、异步反馈、多事务端点和 DSD。详见 [USB 独占输出](usb-audio)。

### 局域网“控制”“投放”和“一起放”有什么区别？

控制只远程操作对端播放器；投放传输当前弥乐播放的 PCM 音频；传输把曲目交给对端自行解析；一起放让多台设备协调同一队列。详见[局域网设备互联](lan-cast)。

### 开发版可以覆盖正式版吗？

不可以。开发版使用 Android debug 签名，正式版使用 MeloX 发布签名。卸载后切换安装会删除应用本地数据，请先确认备份。

### 在哪里报告问题？

可通过 [GitHub Issues](https://github.com/lladlam/MeloX-Android/issues) 反馈。请按[如何有效反馈问题](asking-for-help)提供复现步骤；分享日志前检查并移除账号或 URL 中的敏感信息。
