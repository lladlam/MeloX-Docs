# 常见问题

### 弥乐需要 Root 吗？

正常播放不需要 Root。部分可选设备厂商集成可能有额外前置条件；不使用这些功能时无需配置。

### 所有第三方音源都能用吗？

不能保证。第三方音源依赖外部脚本和服务，可能失效、限流、受地区限制或只提供试听资源。请只导入可信来源的脚本。

### 为什么 USB DAC 被系统识别但弥乐无法使用？

系统识别和当前驱动支持是两回事。当前 USB 独占仅覆盖部分 UAC1 设备，尚不支持 UAC2、异步反馈、多事务端点和 DSD。详见 [USB 独占输出](usb-audio)。

### 开发版可以覆盖正式版吗？

不可以。开发版使用 Android debug 签名，正式版使用 MeloX 发布签名。卸载后切换安装会删除应用本地数据，请先确认备份。

### 在哪里报告问题？

可通过 [GitHub Issues](https://github.com/lladlam/MeloX-Android/issues) 反馈。请附上版本与复现步骤；分享日志前检查并移除账号或 URL 中的敏感信息。
