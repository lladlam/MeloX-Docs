# 音乐音源

弥乐提供多种内置音乐服务，并支持用户导入兼容的第三方 LX Music 音源脚本。音源是否能搜索或播放取决于服务接口、账号权限、地区和资源版权状态。

## 切换当前音源

在应用的音乐服务/音源选择入口切换当前音源。切换只改变内容数据来源，不会自动更换播放器、歌词样式、背景或其他外观偏好。每个音乐服务的账号登录状态单独保存；退出一个服务不会退出其他服务。

当前 Android 版可见的内置服务包括：

| 服务 | 登录/配置说明 | 使用提示 |
|---|---|---|
| 网易云音乐 | 可通过服务页登录 | 账号权限影响歌曲、歌单及可用音质；功能范围最完整 |
| QQ 音乐 | 在服务页登录或重新登录 | 使用独立账号状态，不与其他服务共享登录 |
| 酷狗概念版 | 按服务页提示登录 | 与酷狗标准版账号和会话区分 |
| 汽水音乐 | 支持扫码登录 | 部分登录态功能以服务端当前可用性为准 |
| Bilibili | 按服务页提示登录 | 可用内容和播放受平台接口与资源限制 |
| Spotify | 需要 OAuth 授权，并由用户填写 Client ID | 目录/播放能力依地区、账号和接口状态而异 |
| YouTube Music | 当前搜索和播放为匿名方式 | 不要求登录；不提供账号专属功能 |
| Jellyfin | 连接用户自行管理的 Jellyfin 服务器 | 输入服务器地址和账号；连接信息保存在本机 |
| 本地音乐 | 无需登录 | 文件留在设备本地，可扫描媒体库或授权文件夹 |

服务可见性和功能会随版本、地区和应用兼容设置变化，以应用当前页面为准。某些底层模型或历史迁移中出现的服务不一定作为当前 Android 版可选音源提供。

## 跨平台搜索与自动回退

“跨平台音乐”默认关闭。开启后还要选择参与搜索的音源；列表默认不会悄悄请求所有平台。选择音源时，可只勾选已登录且愿意使用的服务。

播放解析的回退顺序是：

1. 当前歌曲所在的音源。
2. 若开启“不可用资源从其他平台获取”，按严格歌曲匹配尝试已选内置音源。系统要求曲名、歌手和时长足够匹配，避免用同名翻唱、现场版或试听片段替代完整歌曲。
3. 若另外开启第三方音源并接受对应协议，再尝试已导入 LX 脚本或已配置的 CHKSZ 解析服务。

可用音源未匹配成功时，歌曲仍会被视为不可播放；回退不保证一定能找到资源，也不会把试听片段冒充完整音频。跨平台自动回退和主动搜索是不同设置：前者用于当前歌曲解析失败后的尝试，后者用于主动聚合搜索结果。

## 第三方音源与协议

第三方音源需在音乐服务设置里启用并阅读、接受专用条款。此开关由本机控制，不由云控代替用户开启。

### 导入 LX Music 脚本

1. 在“音乐服务”中打开第三方音源设置并接受专用协议。
2. 选择添加 LX Music 音源。
3. 选择本地 JavaScript 文件，或输入脚本的 HTTP/HTTPS 地址并导入。
4. 确认来源可信后再调用脚本；导入列表可查看、移除已添加脚本。

脚本在受限 QuickJS 环境中运行，不代表脚本本身可信。脚本可能向其作者配置的网络服务发送歌曲标识、搜索内容或请求参数。不要导入来历不明的脚本，也不要在脚本中放入不愿交给第三方服务的凭据。

为兼容部分历史脚本，脚本导入、脚本请求和第三方媒体播放使用隔离的网络通道；普通应用网络仍默认禁止明文 HTTP。HTTP 不加密，网络服务或中间网络可能读取或篡改传输内容。优先使用可信 HTTPS 地址，或从本地导入脚本。

MeloX 兼容 LX Music 音源接口，但不是完整 LX Music 客户端；脚本声明的服务、质量和动作决定实际能力。歌单、搜索、登录等功能不能仅凭“LX 兼容”推断为受支持。

### CHKSZ 解析服务

CHKSZ 是可选的个人 API 解析服务，并非弥乐内置服务。需先在应用中开启第三方音源并接受协议，再按设置页面指引申请并填写自己的 API Key。当前注册条件可能受服务方限制，密钥保存在本机，不属于弥乐云控设置；不要将密钥贴到公开问题或截图中。

### 播放失败

脚本接口变更、失效、限流、链接过期、目标音源无资源或服务端策略变化都可能造成失败。检查脚本来源与更新状态，先试原音源或其他内置音源；需要报告问题时可参考[如何有效反馈问题](asking-for-help)。导出日志前检查其中的请求地址和账号信息。
