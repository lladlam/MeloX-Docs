# 音乐音源

弥乐提供多种内置音乐服务，并支持用户导入兼容的第三方 LX Music 音源脚本。音源是否能搜索或播放取决于服务接口、账号权限、地区和资源版权状态。

## 内置音源

应用内的音源选择和设置页面会显示当前版本可用的服务。登录某个服务后，相关账号歌单和登录态能力才可使用；切换音源不会把一个服务的账号凭据当作另一个服务的登录信息。

## 导入 LX 音源脚本

在音乐服务设置中选择导入 LX 音源，可从本地文件导入，或提供脚本地址。仅导入你信任的脚本：第三方脚本可能访问其配置的网络服务，且可能随上游更新改变行为。

导入后可在音乐服务列表查看脚本及其声明支持的音源和功能。脚本返回的音质、歌词或封面能力以脚本自身声明和实际结果为准。

### HTTP 与 HTTPS

为兼容部分历史音源，脚本导入、脚本请求和第三方媒体播放使用隔离的网络通道；普通应用网络仍默认禁止明文 HTTP。HTTP 本身不加密，网络服务可能读取或修改传输内容。优先使用可信 HTTPS 地址，或从本地导入脚本。

### 播放失败

脚本接口变更、失效、限流、链接过期或无法获取目标音源资源都可能造成失败。可以检查脚本是否更新、尝试其他音源，并在导出日志前检查其中的请求地址和账号信息。
