# 播放与歌词

## 音质

播放音质受当前音源和曲目资源限制。选择的音质若不可用，应用或音源脚本可能尝试较低音质；第三方音源报告的音质能力不一定等于服务端实际返回的音质。

## 队列与播放控制

播放器支持队列控制、播放模式切换、进度跳转和系统媒体控制。通知栏与锁屏控制由 Android 系统媒体会话提供，部分厂商系统可能对后台运行施加额外限制。

## 歌词

歌词来自当前曲目对应的音乐服务或受支持的歌词加载链。不同来源可能提供原文、翻译、罗马音或逐字时间轴，实际显示取决于资源内容。歌词缺失时可尝试刷新、切换来源或重新打开曲目。

## 自动混音

自动混音是实验性播放功能。部分播放器输出路径（包括 USB 独占输出）与自动混音不兼容时，应用会避免同时启用冲突路径。
