# 播放与歌词

## 播放器与队列

播放页提供播放/暂停、上一首/下一首、进度调整和当前歌曲信息。打开播放队列可查看待播内容、播放指定歌曲、调整顺序或将歌曲插入队列；不同页面的菜单项目可能因内容类型不同而变化。

通知栏和锁屏控制通过 Android 媒体会话工作。若后台播放停止，先在系统设置中允许弥乐后台运行，并检查厂商的省电/自启动限制。

## 音质

网易云音源按应用音质选项请求标准、高品质、无损、Hi-Res、高清环绕声、沉浸环绕声或超清母带资源。实际可播放音质由歌曲资源、账号权益、地区和服务端响应共同决定；目标资源不可用时会尝试可用降级，并尽量显示实际返回等级。

其他音源的质量档位和降级由各自服务或 LX 脚本决定，显示的档位不一定能证明服务端交付了对应规格。无损/高解析标记也不等于输出链路 bit-perfect。

## 播放模式、均衡器与定时

播放模式可在播放器或通知控制中切换；设置页可配置部分通知按钮。均衡器和音量模式会影响实际输出信号。睡眠定时到时会按界面设置结束播放。各功能入口和可选项以当前版本 UI 为准。

## 歌词

歌词由曲目服务或应用支持的歌词链加载。不同来源可能提供原文、翻译、罗马音、逐字时间轴或伴唱轨；内容和时间轴质量取决于资源。第三方播放源的歌词仍按弥乐自己的歌词路线处理，不保证由第三方脚本提供。

歌词缺失或不同步时：

1. 检查网络和曲目是否能正常识别。
2. 在歌词页面使用刷新/重新加载入口（如果当前页面提供）。
3. 对比歌词开头和实际演唱时间；有同步偏移时可调整歌词时间偏移。
4. 若曲目版本不一致（现场版、翻唱、剪辑版），尝试匹配同一录音版本。

系统歌词、歌词通知和悬浮歌词是不同展示入口；Android/OEM 可能需要额外通知或悬浮窗权限。悬浮窗不可用时仍可在应用内查看歌词。

## 自动混音

自动混音会预载下一首并尝试分析、规划两首歌曲间的过渡。歌曲资源、解码情况和播放路径会影响过渡结果；不保证每首歌都能实现理想节拍或无缝衔接。USB 独占输出与自动混音互斥，切换输出时应用会处理冲突路径。

## 播放失败或无声

先检查当前输出设备、设备音量/静音状态和歌曲是否仍有可用资源。试播同一服务的另一首歌可帮助判断是单曲资源问题还是音源问题。进一步排查见[故障排查](troubleshooting)。
