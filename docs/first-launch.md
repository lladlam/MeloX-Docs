# 首次启动

首次打开弥乐会显示引导流程，依次了解应用、账号、隐私政策与免责声明，以及可选云控设置。请按实际需要完成设置；可选服务不启用也不影响基本播放功能。

## 账号与音源

账号凭据按对应服务单独保存。登录后可使用该服务提供的账号歌单、收藏或其他需要登录态的功能。不同音源的账号彼此独立。

如果暂时不想登录，可以跳过并先体验无需登录的页面与功能。外部音乐服务的权限、登录方式和接口变化由服务提供方决定。

## 云控与可选集成

云控和设备厂商集成属于可选功能。启用前请阅读应用内的功能说明；如果设备不支持或相关服务不可用，可关闭对应集成后继续使用播放器。

## 后续更改

可在应用的设置页面管理音源、账号、实验性功能和设备连接。设置项会随版本变化；遇到文档与当前界面不一致时，以应用内最新提示为准。
