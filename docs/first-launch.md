# Android 首次启动

本页讲解 Android 应用的首次启动流程。桌面客户端的设置界面和权限模型不同，请参考各自项目 README。

首次打开弥乐会显示引导流程，依次了解应用、账号、隐私政策与免责声明，以及可选云控设置。请按实际需要完成设置；可选服务不启用也不影响基本播放功能。隐私政策和免责声明之后可在设置中重新查看。

## 建议的首次设置顺序

1. 选择默认音乐服务；暂时不想登录时可先浏览无需登录的功能。
2. 进入该服务的账号页面，按页面提示完成登录或令牌配置。
3. 如要使用本机音乐，打开“音乐服务 → 本地音乐”，扫描 Android 媒体库，或授权一个音乐文件夹。
4. 按需配置播放器音质、通知/系统歌词、下载位置和设备连接等功能。
5. 只有明确需要第三方脚本或解析服务时，才在音乐服务设置中启用第三方音源并阅读专用条款。

账号凭据按对应服务单独保存。登录后可使用该服务提供的账号歌单、收藏或其他需要登录态的功能。切换当前音源不会把一个服务的凭据传给另一个服务。部分服务可匿名使用或无需账号；外部服务的登录方式、访问权限和接口由服务提供方决定。

## 权限与可选功能

- **本地音乐扫描**：需要媒体/音乐文件读取权限。也可以通过系统文件选择器授权指定文件夹；授权只用于读取本地文件。
- **悬浮歌词**：需要用户在 Android 系统设置中授予“显示在其他应用上层”等权限。未授权时可继续使用应用内歌词。
- **USB 音频**：连接设备后由 Android 弹出 USB 访问授权；系统授权不代表设备协议一定受当前驱动支持。
- **局域网设备**：需要网络访问；连接新设备时通常需要输入接收设备显示的配对 PIN。
- **第三方音源**：必须由用户手动启用并接受条款；不使用时保持关闭即可。
- **云控与 OEM 集成**：属于可选设置。启用前阅读应用内说明；设备不支持时可关闭对应集成，基本播放仍可使用。

## 推荐先完成一次播放

选择音源并播放一首可用曲目，确认通知栏媒体控制正常。之后再尝试下载、外接输出或第三方回退。分步启用可以更容易判断权限或服务配置造成的问题。

可在设置页面管理音源、账号、实验性功能和设备连接。设置项会随版本变化；遇到文档与当前界面不一致时，以应用内最新提示为准。
